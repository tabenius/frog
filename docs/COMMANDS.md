## `frog export`

Export tasks (markdown checkboxes)


### `frog export todo`

Emit in-scope tasks as a markdown checkbox list

- `--repo` — Scope to a repo ('.' = cwd repo; omit = all tasks)
- `--status` — Filter by workflow status
- `--tree` — Nest dependents under dependencies (connectors left of the box)
- `--out` — Write the whole FILE (default: stdout)
- `--into` — Replace a marked section inside FILE in place
- `--marker` — Section marker name (default: todo -> <!-- frog:todo -->)
- `--section` — With --into: replace under the Markdown heading HEADING (## HEADING / ### HEADING, any level) instead of using <!-- frog --> markers
